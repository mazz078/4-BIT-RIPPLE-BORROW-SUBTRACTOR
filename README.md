# 4-Bit Ripple Borrow Subtractor using Verilog

## 📌 Project Overview

This project implements a **4-bit Ripple Borrow Subtractor** using Verilog HDL.

A Ripple Borrow Subtractor performs subtraction of two 4-bit binary numbers by connecting four Full Subtractor modules.

The borrow generated by each lower-order bit is passed to the next higher-order bit.

---

## 🎯 Objective

The objective of this project is to design and verify a 4-bit Ripple Borrow Subtractor using Verilog HDL.

The project demonstrates:

* Hierarchical design
* Full Subtractor instantiation
* Borrow propagation
* 4-bit binary subtraction
* Functional verification

## 🔢 Inputs and Outputs

| Signal     | Width | Description          |
| ---------- | ----: | -------------------- |
| A          | 4-bit | Minuend              |
| B          | 4-bit | Subtrahend           |
| Bin        | 1-bit | Initial borrow input |
| Difference | 4-bit | Subtraction result   |
| Bout       | 1-bit | Final borrow output  |

---

## ⚙️ Working Principle

The circuit consists of four Full Subtractors:

```text
             Borrow
               │
               ▼
A0 ────────► FS0 ───────► Difference[0]
B0 ────────►     │
                 │ B1
                 ▼
A1 ────────► FS1 ───────► Difference[1]
B1 ────────►     │
                 │ B2
                 ▼
A2 ────────► FS2 ───────► Difference[2]
B2 ────────►     │
                 │ B3
                 ▼
A3 ────────► FS3 ───────► Difference[3]
B3 ────────►     │
                 ▼
               Bout
```

The borrow propagates from the least significant bit toward the most significant bit.

---

## 📋 Example

Consider:

```text
    1001
  - 0011
  ------
    0110
```

Therefore:

```text
Difference = 0110
Bout = 0
```

which represents decimal `6`.

---

## 🔢 Example with Borrow

Consider:

```text
    0101
  - 1001
  ------
```

Since `5 < 9`, a final borrow is generated.

The 4-bit result is:

```text
Difference = 1100
Bout = 1
```

The result is interpreted using the borrow output to indicate that the subtraction was negative.

---

## 🧩 Hierarchical Design

The project uses a separate Full Subtractor module.

Four Full Subtractors are connected together:

```text
FS0 → FS1 → FS2 → FS3
```

Internal borrow signals:

```text
B1
B2
B3
```

## ⚠️ Limitation

Similar to a Ripple Carry Adder, the Ripple Borrow Subtractor has propagation delay because the borrow must travel through each Full Subtractor.

For larger bit widths, faster subtraction architectures can be used.

 ```verilog
`timescale 1ns/1ps

module full_subtractor (
    input  wire a,
    input  wire b,
    input  wire bin,
    output wire difference,
    output wire bout
);

    // Difference
    assign difference = a ^ b ^ bin;

    // Borrow output
    assign bout = (~a & b) | (~a & bin) | (b & bin);

endmodule
```
```verilog
`timescale 1ns/1ps

module ripple_borrow_subtractor_4bit (
    input  wire [3:0] a,
    input  wire [3:0] b,
    input  wire bin,
    output wire [3:0] difference,
    output wire bout
);

    // Internal borrow signals
    wire b1;
    wire b2;
    wire b3;

    // Least Significant Bit
    full_subtractor FS0 (
        .a(a[0]),
        .b(b[0]),
        .bin(bin),
        .difference(difference[0]),
        .bout(b1)
    );

    // Second Bit
    full_subtractor FS1 (
        .a(a[1]),
        .b(b[1]),
        .bin(b1),
        .difference(difference[1]),
        .bout(b2)
    );

    // Third Bit
    full_subtractor FS2 (
        .a(a[2]),
        .b(b[2]),
        .bin(b2),
        .difference(difference[2]),
        .bout(b3)
    );

    // Most Significant Bit
    full_subtractor FS3 (
        .a(a[3]),
        .b(b[3]),
        .bin(b3),
        .difference(difference[3]),
        .bout(bout)
    );

endmodule
```
